# WizScroll

A calm, vertically-scrollable feed of educational quote cards. Built with Flutter + Firebase.

> **"An antidote to doomscrolling."**

## Getting Started

### Prerequisites

- Flutter SDK ≥ 3.47.4 (installed to `C:\flutter`)
- Android Studio (for Android emulator/device)
- A Firebase project with Cloud Firestore enabled

### Firebase Setup

1. **Create a Firebase project** (if not already done):
   ```bash
   firebase login
   firebase projects:create wizscroll-app
   ```

2. **Enable Firestore** in the [Firebase Console](https://console.firebase.google.com) under *Build → Firestore Database*.

3. **Configure FlutterFire** — run inside `d:\Scroll App\wizscroll\`:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure --project=<your-firebase-project-id>
   ```
   This generates `lib/firebase_options.dart` with real credentials. **The placeholder file must be replaced before the app will connect to Firebase.**

4. **Import seed quotes** — use the Firestore console or a script to import your 20 JSON documents into the `quotes` collection.

### Running the App

```bash
cd "d:\Scroll App\wizscroll"
flutter pub get
flutter run
```

## Firestore Data Model

Collection: `quotes`

| Field | Type | Notes |
|---|---|---|
| `quoteText` | string | The quote body |
| `author` | string | Author's name |
| `authorCategory` | string | philosopher / scientist / mathematician / writer / activist / statesman / other |
| `source` | string | Editorial source reference |
| `confidence` | string | verified / commonly_attributed |
| `categoryTags` | array | Topic tags |
| `explanation` | string | 2–4 sentence explanation |
| `realLifeScenarios` | array | Practical application examples |
| `likeCount` | number | Engagement counter |
| `createdAt` | timestamp | Used for ordering |
| `active` | boolean | **Only `true` quotes appear in the feed** |
